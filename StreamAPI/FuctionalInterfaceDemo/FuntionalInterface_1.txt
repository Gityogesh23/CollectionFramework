Functional Interface
A Functional Interface is an Interface which allows only Single Abstract method 
within the Interface scope. There are some predefined functional interface in Java like 
Ex. Predicate, consumer, supplier,Callable, etc. 

The return type of a Lambda function 
(introduced in JDK 1.8) is a also functional interface. The Functional Interface 
PREDICATE is defined in the java.util.function packages.
